\section{Introduction}

Information Retrieval (IR) serves as the core foundational pillar for contemporary search engines, question-answering systems, enterprise knowledge bases, and modern Retrieval-Augmented Generation (RAG) frameworks. Historically, Information Retrieval has been dominated by sparse lexical matching paradigms. In these traditional formulations, documents are represented as high-dimensional, sparse term-vectors, and relevance is calculated by matching exact lexical tokens indexed in inverted dictionaries. Prominent mathematical representations such as Term Frequency--Inverse Document Frequency (TF-IDF) and the probabilistic Okapi BM25 framework provide highly efficient, mathematically sound, and computationally lightweight retrieval over massive corpora.

However, purely lexical retrieval architectures suffer from fundamental linguistic bottlenecks:
\begin{enumerate}[label=(\alph*)]
    \item \textbf{Vocabulary Mismatch Problem:} Users frequently formulate queries using terminology that differs from the exact lexical phrasing employed by the document author. For example, a user querying \textit{``automobile shares plunge''} will receive zero relevance scores from a classical inverted index if the target news article exclusively uses the synonyms \textit{``car stock market crash''}.
    \item \textbf{Term Saturation and Document Length Bias:} Uncalibrated term counters heavily favor documents that artificially repeat query terms, necessitating non-linear saturation factors and rigorous document-length penalties.
    \item \textbf{Lack of Semantic Context:} Lexical models treat words as atomic, independent entities (under the "bag-of-words" assumption), disregarding semantic nuances, polysemy, syntactic dependencies, and conceptual relationships.
\end{enumerate}

The advent of deep bidirectional transformer architectures and pre-trained dense encoders—such as Sentence Transformers (Sentence-BERT)—has revolutionized semantic retrieval. Dense retrievers map variable-length passages into continuous low-dimensional vector spaces (e.g., 384 dimensions) where semantic proximity corresponds directly to geometric distance (measured via Cosine Similarity). Consequently, dense retrievers excel at understanding synonyms, contextual semantics, and conceptual intent. Nevertheless, dense semantic retrieval is not a universal panacea:
\begin{itemize}
    \item Dense models frequently suffer from \textit{semantic drift}, where they retrieve thematically related articles while failing to prioritize exact named entities, unique IDs, model numbers, or rare technical terminology.
    \item Dense vector operations require substantial memory and compute overhead ($\mathcal{O}(N \cdot D)$ dot products) compared to rapid, sub-millisecond inverted index lookups.
\end{itemize}

To synthesize the complementary strengths of exact lexical precision and dense semantic understanding, this project builds and evaluates an enterprise-grade **Hybrid Information Retrieval System** based on **Reciprocal Rank Fusion (RRF)** for categorized news archives. By combining Okapi BM25 and dense Sentence Transformers through a rank-positional aggregator, our architecture eliminates score calibration distortion while delivering state-of-the-art ranking quality.

\subsection{Project Objectives}
The central objectives executed in this project are:
\begin{itemize}
    \item To construct an end-to-end modular IR pipeline on the benchmark **BBC News Archive** (2,225 articles).
    \item To implement, evaluate, and compare four ranking paradigms: TF-IDF Vector Space Model, Okapi BM25, Dense Sentence Transformers, and Hybrid Reciprocal Rank Fusion (RRF).
    \item To engineer practical innovations that elevate search utility:
    \begin{itemize}
        \item Automated synonym injection via **WordNet Query Expansion**.
        \item Sub-second answer extraction via **Query-Focused Extractive Summarization**.
        \item Visual Explainable AI using **3D Principal Component Analysis (PCA)** vector projection.
        \item Live document classification and dynamic index ingestion using **Logistic Regression** (achieving 96.63\% accuracy).
    \end{itemize}
    \item To perform rigorous empirical evaluation utilizing industry-standard IR benchmarks: Precision@10, Recall, Mean Average Precision (MAP), and Normalized Discounted Cumulative Gain (nDCG@10).
\end{itemize}

\section{Methodology}

To resolve the dual bottlenecks of lexical vocabulary mismatch and dense semantic drift, our system implements a systematic \textbf{Five-Stage Hybrid Information Retrieval Pipeline}. Rather than forcing a single model to handle disparate search intents, the architecture decouples lexical exact-matching from neural semantic understanding, harmonizing them at a dedicated rank aggregation layer. Figure~\ref{fig:pipeline_arch} illustrates the comprehensive end-to-end architectural flowchart.

\begin{figure}[H]
\centering
\includegraphics[width=0.92\linewidth]{figures/pipeline.png}
\caption{Architectural Flowchart of the Five-Stage Hybrid Reciprocal Rank Fusion Retrieval Pipeline.}
\label{fig:pipeline_arch}
\end{figure}

The five operational stages of the pipeline are structured as follows:

\subsection{Stage 1: Query Ingestion and Pre-Retrieval Expansion}
When a user submits an arbitrary natural language query $Q$, relying solely on verbatim keywords exposes the system to vocabulary mismatch. Our pipeline introduces an automated pre-retrieval query expansion step leveraging Princeton's **WordNet** lexical ontological database:
\begin{enumerate}[label=(\alph*)]
    \item \textbf{Token Extraction:} Query $Q$ is tokenized, lowercased, and filtered against non-content stop words.
    \item \textbf{Synset Mining:} For each content word $w \in Q$, the system queries WordNet to extract cognitive synonym sets ($\text{synsets}(w)$) and associated lemmas.
    \item \textbf{Semantic Query Formulation:} High-confidence synonyms are appended to synthesize an enriched query string $Q_{\text{expanded}}$, bridging lexical gaps before search evaluation while retaining the concise original query $Q$ for dense neural encoding.
\end{enumerate}

\subsection{Stage 2: Dual-Stream Indexing and Document Representation}
A fundamental insight of modern NLP is that classical lexical search and deep transformer encoders require fundamentally conflicting text preprocessing. To maximize the performance of both paradigms, our pipeline introduces a **Dual-Stream Indexing Architecture**:

\begin{enumerate}[label=\textbf{Stream \Alph*:}]
    \item \textbf{Sparse Lexical Processing Stream (BM25 \& TF-IDF):}
    \begin{itemize}
        \item \textit{Normalization \& Cleaning:} Punctuation, non-alphanumeric noise, and URLs are stripped using optimized translation tables.
        \item \textit{Stop-Word Elimination:} High-frequency grammatical words (e.g., \textit{``the''}, \textit{``is''}, \textit{``and''}) are pruned using NLTK's English stopword corpus.
        \item \textit{Morphological Stemming:} Words are stemmed to their root morphological base using the \textbf{Porter Stemmer} (e.g., \textit{``investments''} $\rightarrow$ \textit{``invest''}, \textit{``computing''} $\rightarrow$ \textit{``comput''}).
        \item \textit{Inverted Index Construction:} An inverted index data structure is constructed mapping each unique stemmed vocabulary term $t$ to its posting list $\mathcal{P}(t) = \{(d_1, f_1), (d_2, f_2), \dots\}$, enabling $\mathcal{O}(1)$ posting traversal.
    \end{itemize}

    \item \textbf{Dense Semantic Processing Stream (Sentence Transformers):}
    \begin{itemize}
        \item Unlike the lexical stream, the dense encoder is provided with **raw, grammatically intact sentences**. Deep bidirectional transformers rely on multi-head self-attention mechanisms; stripping stop words or applying aggressive stemming degrades syntax and compromises embedding quality.
        \item Long news articles are contextually chunked to a window of 300 words to preserve the salient journalistic core while conforming to the transformer's token input constraints.
        \item Each document is passed through the pre-trained \texttt{all-MiniLM-L6-v2} neural network, generating a static 384-dimensional dense semantic embedding $\mathbf{v}_d \in \mathbb{R}^{384}$.
    \end{itemize}
\end{enumerate}

\subsection{Stage 3: Multi-Paradigm Retrieval and Scoring Engines}
During retrieval execution, the query is dispatched simultaneously across two independent scoring branches:

\subsubsection{Branch A: Probabilistic Keyword Scoring (Okapi BM25)}
Okapi BM25 evaluates document relevance based on non-linear term frequency saturation and document length normalization:
\begin{equation}
\text{Score}_{\text{BM25}}(D, Q) = \sum_{i=1}^{n} \text{IDF}(q_i) \cdot \frac{f(q_i, D) \cdot (k_1 + 1)}{f(q_i, D) + k_1 \cdot \left(1 - b + b \cdot \frac{|D|}{\text{avgdl}}\right)}
\end{equation}
where $k_1 = 1.5$ regulates term saturation (capping the marginal score boost from repeating terms) and $b = 0.75$ controls the penalty for document length $|D|$ relative to the average length $\text{avgdl}$. This yields a ranked sparse candidate list $\mathcal{L}_{\text{sparse}}$.

\subsubsection{Branch B: Dense Semantic Geometry (Cosine Proximity)}
Simultaneously, the dense transformer encodes the natural query $Q$ into vector $\mathbf{u} \in \mathbb{R}^{384}$. Relevance across all document vectors $\mathbf{v}_d$ is computed via geometric Cosine Similarity:
\begin{equation}
\text{Score}_{\text{Dense}}(Q, D) = \cos(\mathbf{u}, \mathbf{v}_d) = \frac{\mathbf{u} \cdot \mathbf{v}_d}{\|\mathbf{u}\|_2 \|\mathbf{v}_d\|_2}
\end{equation}
This yields an independent ranked dense candidate list $\mathcal{L}_{\text{dense}}$.

\subsection{Stage 4: Reciprocal Rank Fusion (RRF) Aggregation}
Because BM25 outputs unbounded positive scores ($[0, \infty)$) while Cosine Similarity outputs normalized real numbers ($[-1, 1]$), linear score combination ($\alpha S_{\text{BM25}} + (1-\alpha) S_{\text{Dense}}$) is unstable and requires sensitive per-query tuning.

Our pipeline employs **Reciprocal Rank Fusion (RRF)**, which aggregates candidates strictly by their **relative ordinal rank position**:
\begin{equation}
\text{RRF\_Score}(d \in D) = \sum_{m \in M} \frac{1}{k + r_m(d)}
\end{equation}
where $M = \{\text{BM25}, \text{Dense}\}$, $r_m(d)$ represents the 1-based rank position of document $d$ in ranking list $m$, and $k$ is the canonical smoothing constant set to $60$. 

\textbf{Rank Invariance Property:} Documents scoring consistently high across both sparse and dense rankings receive an additive boost, while documents that appear at the top of only one list are gracefully regularized by the $k=60$ harmonic denominator.

\subsection{Stage 5: Post-Retrieval Intelligence and Output Presentation}
Following global candidate ranking, the top-$K$ documents are routed through three specialized downstream intelligence modules:

\begin{enumerate}[label=\textbf{\arabic*.}]
    \item \textbf{Query-Focused Extractive Summarization (Featured Snippets):}
    Rather than displaying arbitrary first-paragraph previews, our extractive engine tokenizes each retrieved article into individual sentences. It computes the Jaccard-style token overlap between each candidate sentence $S_i$ and the query $Q$:
    \begin{equation}
    \text{Score}_{\text{overlap}}(S_i, Q) = \frac{|\text{Tokens}(S_i) \cap \text{Tokens}(Q)|}{|\text{Tokens}(Q)|}
    \end{equation}
    The top 1--2 highest-scoring sentences are extracted and presented as an instant answer snippet. This guarantees 100\% factual grounding with zero risk of generative hallucinations.

    \item \textbf{Explainable AI via 3D PCA Semantic Mapping:}
    To demystify neural representations for non-expert users and evaluators, the system applies **Principal Component Analysis (PCA)** to reduce the 384-dimensional vector space into interactive 3D coordinates $(X, Y, Z)$. The user query and article clusters are plotted in an interactive Plotly universe, visually validating semantic proximity.

    \item \textbf{Real-Time ML News Ingestion Pipeline:}
    To support dynamic media environments, the system integrates a trained **Logistic Regression** classifier on the TF-IDF feature space (achieving 96.63\% validation accuracy). When a user submits breaking news, the system predicts its category and dynamically hot-swaps the document into both the lexical inverted index and dense vector store in under 0.5 seconds without system downtime.
\end{enumerate}


\section{Experimental Setup and Performance Analysis}

\subsection{Evaluation Metrics}
To rigorously quantify retrieval efficacy across our 2,225-document benchmark corpus, we evaluate candidate models using four standardized Information Retrieval metrics:

\begin{enumerate}[label=\textbf{\arabic*.}]
    \item \textbf{Precision@10 (P@10):} Measures the proportion of relevant documents present in the top 10 retrieved results:
    \begin{equation}
    P@10 = \frac{\sum_{i=1}^{10} \text{rel}_i}{10}
    \end{equation}
    where $\text{rel}_i \in \{0, 1\}$ denotes the binary relevance of the document at rank $i$.

    \item \textbf{Recall:} Measures the proportion of all relevant documents in the corpus that were successfully retrieved:
    \begin{equation}
    \text{Recall} = \frac{\sum_{i=1}^{K} \text{rel}_i}{|R|}
    \end{equation}
    where $|R|$ is the total number of relevant documents in the corpus for the given domain.

    \item \textbf{Mean Average Precision (MAP):} The benchmark gold standard evaluating both precision and rank order. For a query $q$ and retrieval depth $K$, Average Precision (AP@K) is computed with a bounded retrieval denominator:
    \begin{equation}
    \text{AP@K} = \frac{1}{\min(K, |R|)} \sum_{k=1}^{K} P(k) \times \text{rel}_k
    \end{equation}
    MAP is the mean AP calculated across the full evaluation query set: $\text{MAP} = \frac{1}{|Q|} \sum_{q \in Q} \text{AP}(q)$.

    \item \textbf{Normalized Discounted Cumulative Gain (nDCG@10):} Assesses ranking quality with logarithmic position penalties, rewarding models that place the most relevant documents at position \#1:
    \begin{equation}
    \text{DCG@10} = \sum_{i=1}^{10} \frac{2^{\text{rel}_i} - 1}{\log_2(i + 1)}, \quad \text{nDCG@10} = \frac{\text{DCG@10}}{\text{IDCG@10}}
    \end{equation}
    where $\text{IDCG@10}$ is the Ideal DCG obtained by sorting all relevance labels in descending order.
\end{enumerate}

\subsection{Performance Analysis and Discussion}
As reported in Table~\ref{tab:model_comparison}, a distinct evolutionary trajectory in retrieval effectiveness is observed:

\begin{itemize}

This superiority is directly attributed to BM25's non-linear term saturation curve and document-length normalization ($b=0.75$), which prevent word-stuffed and lengthy articles from falsely monopolizing top ranks.
    
    \item \textbf{Why Sentence Transformers Outperform Lexical Models:} The dense Sentence Transformer achieves an impressive MAP of 0.795 and nDCG@10 of 0.884. RRF achieves an approximate \textbf{14.7\% MAP gain over standalone Dense retrieval} and a \textbf{72.1\% MAP improvement over classical BM25}. The synergistic fusion ensures that documents supported by both strong lexical term matches and high semantic cosine scores are prioritized, neutralizing individual model weaknesses.
    
    \item \textbf{Note on Recall Values:} While Precision, MAP, and nDCG achieve exceptional scores, Recall values appear numerically modest ($\approx 0.025$). This is mathematically expected: because each topical category in the corpus comprises $\sim$400--510 relevant articles, evaluating top-$K$ with $K=10$ naturally yields a theoretical maximum recall ceiling of $\frac{10}{400} = 0.025$.
\end{itemize}

\section{Conclusion}

In this work, we developed, implemented, and empirically benchmarked an advanced **Hybrid Information Retrieval System** for the categorized BBC News Archive. Our architecture successfully combines the exact-match efficiency of Okapi BM25 with the contextual semantic depth of pre-trained Sentence Transformers through **Reciprocal Rank Fusion (RRF)**.

The empirical results substantiate that:
\begin{enumerate}
    \item Purely sparse lexical search (TF-IDF/BM25) is computationally fast but fundamentally crippled by vocabulary mismatch and semantic unawareness.
    \item Purely dense semantic search captures deep linguistic concepts but is vulnerable to semantic drift on exact entity matching.
    \item **Reciprocal Rank Fusion provides the optimal synthesis**, achieving an nDCG@10 of \textbf{0.965} and MAP of \textbf{0.912}, outperforming all individual retrieval baselines without requiring complex cross-model score normalization.
\end{enumerate}

Furthermore, the integration of **Query-Focused Extractive Summarization**, automated **WordNet Query Expansion**, **3D PCA Semantic Mapping**, and a **Real-Time Machine Learning Classifier** (96.63\% accuracy) transforms the system into a comprehensive, explainable, and production-ready search and discovery engine.

\subsection{System Limitations}
In the spirit of honest scientific inquiry, two notable limitations are recognized:
\begin{itemize}
    \item \textbf{Dense Compute Overhead:} While BM25 inverted index lookups execute in sub-milliseconds, generating transformer embeddings on CPU requires linear compute scaling ($\mathcal{O}(N)$), necessitating dedicated Vector Databases (e.g., Faiss, Milvus, or Pinecone) for multi-million document corpora.
    \item \textbf{Extractive vs. Generative Synthesis:} The extractive summarizer quotes exact high-overlap sentences. If an answer requires multi-hop synthesis across distinct paragraphs, an extractive approach cannot generate a unified paragraph.
\end{itemize}

\subsection{Future Scope}
Future enhancements will focus on implementing cross-encoder neural re-rankers (e.g., MonoT5) on the top-50 RRF candidates, incorporating Approximate Nearest Neighbor (ANN) indexing via HNSW, and exploring multilingual transformer models for cross-lingual news retrieval.
